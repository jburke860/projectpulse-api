# ProjectPulse Dashboard

Minimal React demo UI for the ProjectPulse API.

## Stack

- React 19 + Vite + TypeScript
- Tailwind CSS v4
- TanStack Query
- React Router

## Run

```bash
npm install
npm run dev
```

Requires the API at `http://localhost:5000` (proxied in dev).

## Hosted Demo Env

For Vercel, set:

```bash
VITE_API_BASE_URL=https://your-projectpulse-api-host
VITE_API_DOCS_URL=https://your-projectpulse-api-host/swagger
```
